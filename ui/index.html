语音
—
遥控器走 HID 键盘通道，Windows 无法把它和物理键盘区分开。开启后，物理键盘的 Enter / Esc / 方向键也会一起被吞掉。不勾选时遥控器原生按键直接生效。
不勾选时确认键仍会结束语音，但会额外打出一个回车。Windows 分不出遥控器和物理键盘，所以勾上后物理键盘的 Enter 也会一起被吞 —— 想一边说话一边敲键盘就取消勾选。
默认：说完 → 文字落进输入框 → 什么时候发由你决定（改完按键盘回车就行， 手本来就在键盘上 —— 原来别扭的是"得去够鼠标点一下"。）
勾上会发生什么：按语音键结束后，程序等一会儿就替你按发送键。 也就是说，你说到一半去倒杯水、回来想接着改，话可能已经被发出去了 —— 发到哪、发给谁都不再由你把关。所以除非你确定"每次说完都是想直接发"，否则别勾。
发送键 延迟 ms
延迟是等输入法把识别结果落进输入框——调太小会在文字进去之前就回车，等于把刚说的话弄丢一次，别低于 300ms。
勾上之后也有几道保护：结束马上又开始说下一段 → 上一条自动取消； 这一段一帧音频都没收到（误触）→ 不发；挂着忘了关（超时收尾）→ 永不发送。
