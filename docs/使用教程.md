# Remote Voice Bridge 使用教程（Windows）

[← 回 README](../README.md)　|　[更新日志](../CHANGELOG.md)

从零到能用，跟着做即可。全程约 10 分钟，其中装驱动要重启一次。

---

## 0. 你需要准备什么

| 类别 | 要求 |
|---|---|
| 遥控器 | Chromecast Voice Remote（`18D1:9450`）或 X6 Remote（`1D5A:C081`） |
| 电脑 | Windows 10 / 11，**蓝牙 4.0+（支持 BLE）**——2013 年后的笔记本基本都行；老机器（如蓝牙 3.0 的 ThinkPad T420）扫不到，见[常见问题](#常见问题) |
| 软件 | [VB-CABLE](https://vb-audio.com/Cable/)（免费虚拟声卡）+ 本程序 |

**它到底在干什么？**

```
遥控器 ──蓝牙/BLE──▶ 本程序 ──解码语音──▶ VB-CABLE 虚拟声卡 ──▶ 微信/输入法当成麦克风用
```

遥控器的麦克风本来只能给电视盒子用，这个程序把它「搬」到电脑上，
让微信输入法、豆包输入法以为你在对着电脑麦克风说话。

---

## 关于驱动：只有 VB-CABLE 要装

很多人会问"遥控器要不要装驱动"——**不用**。

| 组件 | 要装驱动吗 | 说明 |
|---|---|---|
| 蓝牙遥控器（Chromecast / X6） | ❌ **不用** | Windows 10/11 自带蓝牙 HID 驱动，配对后自动装好，按键直接当键盘输入 |
| **VB-CABLE 虚拟声卡** | ✅ **必须装** | 唯一需要手动装的驱动，且装完**必须重启电脑** |
| Interception（按键合成驱动） | ❌ 不用（可选） | 程序检测不到会自动降级用系统按键库，不影响使用 |

原因是遥控器的两部分走不同通道：

- **按键** → 标准蓝牙 HID，Windows 自动识别成"符合 HID 标准的键盘"，配对即用；
- **语音** → 不走 HID，走蓝牙 GATT（ATVV 协议），由本程序直接读取——
  **系统层面根本不存在"遥控器语音驱动"这种东西**。

> 配对后如果在「设备管理器」里看到黄色感叹号或"其他设备"，一般不影响使用，可以不管。

## 第一步：装 VB-CABLE（虚拟声卡）

⚠️ 这一步必须做，且**装完要重启电脑**，否则后面的设备名不会出现。

1. 打开 <https://vb-audio.com/Cable/>，点 **Download**，下载 `VBCABLE_Driver_Pack43.zip`（约 1MB）。
2. 解压，找到 **`VBCABLE_Setup_x64.exe`**。
3. **右键 → 以管理员身份运行**（必须管理员，否则装不上）。
4. 点 **Install Driver** → 等进度条走完 → 点 OK。
5. **重启电脑**。

重启后验证：右下角音量图标 **右键 → 声音设置**，在「输出」和「输入」列表里应该都能看到 `CABLE` 字样，说明装好了。

---

## 第二步：配对遥控器

### Chromecast Voice Remote

1. 电脑上打开：**设置 → 蓝牙和设备 → 添加设备 → 蓝牙**。
2. 遥控器：**同时按住「Home 键」和「返回键」**，按住 3–5 秒不要松。
3. 遥控器指示灯开始闪烁，电脑列表里出现 **Chromecast Voice Remote** → 点击它 → 连接。
4. 显示「已连接」即可。

### X6 Remote

按遥控器说明书的配对组合键进入配对模式，然后在电脑蓝牙列表里连接。

> 配对成功后，遥控器的按键会像外接键盘一样工作（方向键、音量键等）。
> 如果列表里找不到设备，把遥控器靠近电脑一点，或者换一组新电池再试。

---

## 第三步：把麦克风指向 CABLE（最容易做错的一步）

⚠️ **VB-CABLE 的命名是反的**，这是 90% 的人第一次配不通的原因：

| 你看到的名字 | 它其实是什么 | 谁该用它 |
|---|---|---|
| `CABLE Input` | **播放**设备（扬声器那一类） | **本程序**把语音送到这里 |
| `CABLE Output` | **录音**设备（麦克风那一类） | **微信 / 输入法**的麦克风选这个 |

**操作：**

1. **系统层面**：设置 → 系统 → 声音 → **输入** → 选择 **`CABLE Output (VB-Audio Virtual Cable)`**
2. **微信层面**（如果只想让微信用）：微信 → 设置 → 语音视频 → 麦克风 → 选 **`CABLE Output`**

> 一句话记住：**程序 → `CABLE Input`，微信 → `CABLE Output`**。名字里的 Input/Output 说的是"线缆的两头"，不是"电脑的输入输出"。

## 第四步：安装本程序

1. 打开 **Releases** 页面，下载 **`RemoteVoiceBridge-Setup-1.0.8.exe`**（约 23MB）。
2. 双击安装。若弹出「Windows 已保护你的电脑」→ 点 **更多信息 → 仍要运行**（未签名软件的正常提示）。
3. 一路下一步，装完会自动启动。
4. 右下角托盘区出现一个**麦克风图标**，说明程序跑起来了。

> 没看到图标？点托盘区的小箭头 `^`，把麦克风图标拖出来固定即可。

> 安装时还会一并装上 **「遥控器诊断」**工具：开始菜单里叫
> **「遥控器诊断（按键没反应时跑这个）」**，也在安装目录下的
> `RemoteVoiceBridgeDiag.exe`。平时用不到，某个按键不对劲时跑它。

## 第五步：开始使用

### 看图标就知道状态

| 图标颜色 | 含义 |
|---|---|
| 灰色 | 未连接（遥控器在睡觉或没配对） |
| 暖橙 | 已连接，随时可用 |
| 橙红 | **正在收音**，可以说话 |

### 说话的正确姿势

**（v1.0.3 起默认就是下面这套，装好即用，不用再设任何东西。）**

1. **先唤醒**：按一下遥控器任意键（方向键 / Home 都行），等 **1–2 秒**。
   —— 遥控器为了省电平时是休眠的，必须先唤醒。
2. **按一下语音键**（带麦克风图标那个键），**然后就可以松手了**。
3. **说话**：图标变橙红，输入法实时把语音转成文字，说多久都行。
4. **结束**：再按一下**语音键**，或按一下**确认键（中间那颗）**。文字落到输入框。

| 遥控器键位 | 怎么用 | 转发给输入法的 |
|---|---|---|
| **语音键**（麦克风图标） | 按一下**开始** → 松手也一直在听 → 再按一下 / 按确认键**结束** | 左Ctrl+左Win+左Shift（输入法的「启动语音输入」） |
| **静音键** | **按住**说话，松手即结束（对讲机式） | Ctrl+Win（输入法的「按住说话」） |

> **松手 ≠ 说完。** 这是本程序最核心的一点：遥控器的麦克风在松手后
> 会被自动重新打开、继续收音，因为"这段语音有没有说完"只有**你按确认/再按语音键**
> 才算数 —— 状态由程序管，不是由遥控器管。
>
> 忘了结束也没关系：**10 分钟**后程序会自动收尾。

> 想要"全程按住才说话"？那就是**静音键**的用法；
> 或者跑一次 `python tools\apply_voice_mode.py --hold` 把整套退回按住模式。

### 托盘右键菜单

| 菜单项 | 作用 |
|---|---|
| 状态 | 显示当前连接状态 |
| **控制台** | 分页窗口：**音频**（波形/电平/增益/输出设备/语音键自测）· **按键映射** · **设置** · **日志**（排错第一步就看这个） |
| **输入法** | 切换微信输入法 / 豆包输入法 / 自定义 |
| 重新连接 | 连不上 / 改完输出设备后按它重建连接（不会另起进程） |
| 开机启动 | 勾选后开机自启 |
| 打开日志 | 打开日志文件 |
| 退出 | 关掉程序 |

### 控制台四个页

| 页 | 能做什么 |
|---|---|
| **音频** | 看实时波形和电平；拖**增益滑块**调音量（立即生效，不用重启）；换**输出设备**；选输入法；点**「测试语音键（长按 1 秒）」**直接验证输入法认不认这组键 |
| **按键映射** | 每个遥控器按键一行，下拉框挑它触发什么动作；也可以选**「录制任意按键…」**自己按一个组合键进去。改动**即时保存、无需重启** |
| **设置** | 上半是**音频**（遥控器/电脑麦克风增益、混合输出设备、电脑麦克风）和**语音**（触发方式、触发键、拦截开关、开机启动）；下半是**连接**（遥控器状态、型号、重新连接）和**关于**（版本、配置目录、打开日志） |
| **日志** | 实时日志。判断语音链路通不通就看两行：`📤 MIC_OPEN`（开麦命令发出去了）→ `🔊 收到第一个音频帧`（遥控器真的在推流） |

**关于「原样直通」**：遥控器走的是 HID 键盘通道，它自己的按键 Windows 本来就收得到。
所以映射目标里有一项 **`原样直通`**（方向键默认就是它）＝ 不做任何额外动作，避免同一个键发两遍。
改成别的动作时会「原生键 + 映射键」一起发出；要完全接管，去「设置」页打开
**「拦截遥控器原生按键」**（代价：物理键盘的同名键也会被吞掉）。

## 第六步：确认触发键（最容易白干的一步）

默认是**微信输入法**，并且**两种方式都给你配好了**（v1.0.3 起开箱即用）：

- **语音键** → 左Ctrl + 左Win + 左Shift（**按一下开始 / 再按一下结束**）
- **静音键** → Ctrl + Win（**按住说话，松手结束**）

这两组键都是**微信输入法原生支持**的（面板「设置 → 语音输入」里就写着），
本程序只是把遥控器的按键转过去 —— 不用在输入法里改任何东西。

### 先分清这两家（90% 的人卡在这）

| 产品 | 「按住说话」的键 | 生效范围 |
|---|---|---|
| **微信输入法** ← 本程序对接的是它 | **Ctrl + Win** | **全局**：微信、豆包、记事本、浏览器……任何输入框都能用 |
| **豆包输入法** | **右 Alt** | 全局（另外可选 右Alt+空格 / 左Ctrl+Win） |

> 🔴 **别再照抄旧文档 / 旧教程里的「微信输入法 = 右 Alt」** ——
> 那是错的（右 Alt 是豆包的键）。**以输入法「设置 → 语音输入」面板里写的为准。**

### 最靠谱的做法：直接看输入法面板

**微信输入法 → 设置 → 语音输入**，上面有两条：

| 面板上的条目 | 键位 | 用哪条 |
|---|---|---|
| **启动语音输入**（按下即开始，再按结束） | 左Ctrl + 左Win + 左Shift | ✅ **遥控器「语音键」用这条**（按一下长输） |
| **按住说话**（按住可语音输入，松手结束） | **Ctrl + Win** | ✅ **遥控器「静音键」用这条**（PTT） |

面板里的键位**是可以改的**，所以先看一眼，再决定 `config.json` 里填什么。

### 怎么确认（30 秒）

1. 打开**记事本**，鼠标点进正文区
2. **按住 `Ctrl + Win` 不放**，说一句话，再松开
3. 看结果：
   - **输入法的语音输入界面弹出来了** → 对了，不用管
   - **没弹** → 回「微信输入法 → 设置 → 语音输入」确认键位，
     再改 `%APPDATA%\remote-voice-bridge\config.json` 里的 `voice_hotkey`
     （例如 `["ctrl","win"]`、`["ralt"]`、`["ralt","space"]`）

如果不想手动一个个试，源码运行时有自检工具（只用标准库，不用装依赖）：

```bat
cd remote-voice-bridge
python tools\test_voice_hotkey.py ctrl win
python tools\test_voice_hotkey.py ralt
python tools\test_voice_hotkey.py ralt space
```

运行后有 5 秒切到记事本，然后它按住那组键 6 秒再松开 —— 输入法界面弹出来就是对。

> ⚠️ **`Ctrl+Win` 有一条系统限制**：Ctrl 已经按下时，系统会把后到的 Win 改写成
> `0xFC`，输入法就认不出 Win 了。程序已经按「**Win 最先落下**」的顺序发（这是合成
> 按键能做到的最好结果），但**务必用上面那条命令实测一次**确认你的输入法认它。
> 实在不行就把输入法的键位改成**右 Alt** —— 那条路不涉及 Win，最干净。

> 顺带一提 v1.0.0 那个最大的 bug：当时把「按住说话」做成了**点一下**，
> 只录到几十毫秒空气。现在的默认（`hotkey_mode = "tap"`）用的是输入法原生的
> **切换式**语音，按一下是"开始"而不是"点一下就完"，两回事。

换豆包：**托盘右键 → 输入法 → 豆包输入法**（豆包的唤起键是**右 Alt**）。

设置会存在 `%APPDATA%\remote-voice-bridge\config.json`，下次启动自动生效。

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 「添加设备」里**永远搜不到**遥控器（指示灯明明在闪） | 电脑蓝牙太老：蓝牙 3.0 不支持 BLE，而本遥控器是**纯 BLE 设备** | 换蓝牙 4.0+ 的电脑，或插一个 USB 蓝牙适配器（认准 **CSR8510** 芯片，免驱，约 15–30 元）；确认方法：设备管理器 → 蓝牙，看模块名（BCM2070=❌无BLE，BCM20702=✅有BLE） |
| 托盘图标一直**灰色** | 遥控器休眠 / 没配对 | 按遥控器任意键唤醒；到蓝牙设置里确认已连接 |
| 图标**橙色**，但说话输入法没反应 | **先看控制台，别猜** | ① 波形**有起伏**却没反应 → 触发键不对，见下两行；② 波形**一直是平的** → 麦克风没选对，把输入设备改成 **`CABLE Output`**（不是 Input） |
| 快捷键到底对不对 | 触发键必须与输入法里的语音唤起键一致 | 记事本里**按住 `Ctrl + Win`** 说一句话，输入法弹出来就是对的；没弹就去「微信输入法 → 设置 → 语音输入」看面板上写的键位，改 `config.json` 的 `voice_hotkey`。⚠️ 微信输入法的「按住说话」就是 `Ctrl+Win`；**右 Alt 是豆包的键**，别填错 |
| 按了没反应，且右键托盘看**输入法选错了** | 托盘「输入法」菜单选了豆包/自定义，但系统里装的是微信输入法 | 托盘右键 → 输入法 → 切回**微信输入法** |
| 控制台显示「⚠ 本次 0 帧」 | 语音开始后遥控器一帧音频都没推上来 | 先看日志里有没有 `📤 MIC_OPEN`：**没有**说明开麦命令没发出去（v1.0.1 及更早的版本就是这样，升级到 v1.0.2+）；**有**但仍 0 帧，就多发几次、把日志发出来定位 |
| 微信收不到声音 | 微信单独设了别的麦克风 | 微信 → 设置 → 语音视频 → 麦克风 → `CABLE Output` |
| 提示 `'CABLE Input' not found` | VB-CABLE 没装 / 装完没重启 | 重装 VB-CABLE 并**重启电脑** |
| 语音声音太小 / 太大 | 增益不合适 | 控制台 → **音频** → 拖**麦克风增益**滑块（1–30x，立即生效）；也可以在「音频」页换输出设备后点底部的**「应用设备设置并重连」** |
| 遥控器的按键按了会触发两次 | 映射到了它本来就有的键（例如确认→Enter） | 控制台 → **按键映射** → 把该键改成 **`原样直通`** |
| 第一次按语音键没反应 | 遥控器刚唤醒还没连上 | 再按一次；或看日志确认连接状态 |
| 说着说着**自己断了**，得再按一下才开始 | 会话中途被一次蓝牙健康检查打扰（v1.0.3 及更早） | 升级到 **v1.0.4 及以后**：语音期间已不再做那次 GATT 读 |
| 语音还开着的时候，**物理键盘的回车按了没反应** | 语音会话进行中，确认键被程序接管去结束语音了；Windows 分不出遥控器和物理键盘 | 按遥控器确认键/语音键收尾即可恢复；想一边说话一边敲键盘 → **设置 → 语音** → 取消勾选「确认键只结束语音」 |
| 升级后**静音键没反应**（旧配置） | 配置是"读旧的、补新的"，旧文件里写死的映射不会被新默认值覆盖 | v1.0.4 及以后会自动迁移一次（日志里会打印「已自动升级旧版配置」）；没生效就去 **按键映射** 页把静音键设成 **`按住说话`** |
| **某个遥控器按键按下没反应** | 可能是这个键根本没发键盘事件，也可能是映射值写错了 | **别猜，让程序测**：先退出桥接程序，再从**开始菜单 →「遥控器诊断」**打开（源码版是仓库里的 `diag-remote.bat`），按提示按一遍键，会生成一份 `remote-diag.txt`，里面直接写明每个键实际发出什么 |
| 蓝牙里明明显示**已连接**，软件却说「没有 Chromecast Voice Remote 连接」，而且**除语音键外所有键都没反应** | 遥控器的按键走的是 **HID**（蓝牙键盘协议），和"蓝牙连上了"是两件事；它一共暴露 5 个 HID 集合，其中**两个是厂商自定义页，Windows 完全不处理** | **先跑快查**（2 秒、不用按键、也不用退程序）：安装版在安装目录执行 `RemoteVoiceBridgeDiag.exe --hid`，源码版 `python tools\diag_remote.py --hid`。它会直接告诉你：键盘那一路有没有被 Windows 绑上、哪几个集合是 Windows 不理的。按它的结论走 |
| 想知道到底哪里出问题 | — | 托盘 → **控制台 → 运行日志**，或看 `%APPDATA%\remote-voice-bridge\bridge.log` |

### 日志与配置位置

```
%APPDATA%\remote-voice-bridge\
├── bridge.log     ← 运行日志，排错先看这个
└── config.json    ← 输入法、增益、按键映射等设置（控制台里改，不用手改这个文件）
```

在文件资源管理器地址栏粘贴 `%APPDATA%\remote-voice-bridge` 回车即可打开。

---

## 卸载

**设置 → 应用 → 已安装的应用 → Remote Voice Bridge → 卸载**

VB-CABLE 如果用不上了，也可以在设备管理器里单独卸载。
日志和配置不会自动删，需要的话手动删掉 `%APPDATA%\remote-voice-bridge` 文件夹。
