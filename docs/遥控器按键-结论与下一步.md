# 遥控器按键：结论与下一步

> 生成时间：2026-09-23 凌晨｜对应版本：v1.0.15
> 面向：武哥。看这一页就够了，不用翻 CHANGELOG。

## 一句话

**按键在 Windows 上全没反应，不是映射表的问题，也不是我少试了哪条通道 ——
是这台遥控器在 Windows 上根本没有 HID 报告的「接收方」。**
修法只有一条：**重新配对一次遥控器**（要你亲手按，程序替不了）。

## 为什么（四条现场证据，都是只读查出来的）

| # | 查到什么 |
|---|---|
| 1 | 遥控器的配对记录里**一个 BLE 密钥值都没有** —— 没有 `LTK`（长期密钥），`IRK`/`CSRK`/`Address`/`KeyLength` 也全缺，只剩下名字、VID/PID 这些元数据 |
| 2 | 配对记录绑的本地蓝牙地址和**当前在用的**适配器地址**对得上** ⇒ **不是**以前那种"记录绑错无线电"的老毛病 |
| 3 | 设备管理器里**一切正常**：8 个服务节点都在场、都已启动，HOGP 驱动绑着，5 路 HID 集合都在（键盘那路绑着 `kbdhid`） |
| 4 | 桥程序自己的 HID 通道审计**跨天 20 条全是 0**；键盘钩子也**从来没**出现过任何遥控器专有的键名 |

**它们不矛盾**：前三条只说明"驱动绑上了"，不等于"密钥有了"。
而 HID over GATT 规范**要求加密链路** —— Windows 手里没有密钥 ⇒
链路加不了密 ⇒ HOGP 永远订阅不到 HID 报告 ⇒ 遥控器把按键发出去，
**没有人接收**。映射表改到天亮也不会有效果。

> 顺带纠正我以前的一个说法：`0x1812` 报 `ACCESS_DENIED` 时我说过
> "被 Windows 的 HOGP 独占"。同一次探测里 **ATVV 也是 `AccessDenied`**，
> 而它是被我们自己的程序占着的 —— 所以这个词只表示"已经有人开着这个服务"，
> **不能**由此推出是谁在占。

## 你要做的（1 分钟，零风险）

1. 遥控器上**同时按住「返回」+「主页」约 3 秒** ——
   底部指示灯开始闪，就是进了配对模式（Google 官方口径，已核实过）。
2. Windows：**设置 → 蓝牙和其他设备** →
   先把列表里旧的「Chromecast Remote」**删除**，再**添加设备 → 蓝牙**。
3. 等它连上，然后按遥控器的 **确认 / 返回 / 主页**。

> ⚠ 删除旧条目是必要的：Windows 里同一个遥控器现在有**两条**已配对记录，
> 其中一条是上一代无线电留下的幽灵（在系统里已经不存在了）。

## 做完马上验（两条命令）

```bat
:: ① 看密钥有没有真的生成 —— 要看到「找到的绑定材料」里出现 LTK
python tools\probe_hogp_state.py

:: ② 长窗口监听（有 3-2-1 倒计时），按遥控器的键，看落在哪条通道
::    要听 ATVV 就先退出桥程序；带着它测就加 --force
python tools\watch_all_channels.py --seconds 90
```

判读：

| 第 ① 步看到 | 含义 | 下一步 |
|---|---|---|
| 出现 `LTK` | 这次配对是**完整**的 | 跑第 ② 步验按键；若按键来了，映射表已经修好（见下） |
| 仍然没有 `LTK` | 这台机器上 Windows 的 HOGP 走不通 | 就当**纯语音遥控器**用（语音键一直好用），按键别指望了 |

## 这次同时修掉的（都是真 bug，不是补丁）

1. **v1.0.14 把语音改坏** → v1.0.15 修回（真机证据：239 次实测里回声延迟最大
   1070ms，而 v1.0.14 的窗口只有 0.8s ⇒ 慢写入那 8 次回声漏出去，
   被当成"又按了一下" ⇒ **按一次掉**）。现在改成"欠账模型"，
   窗口 1.5s 且只靠时间过期。**这一条是真机上能立刻感觉到的。**
2. **三个永远不可能命中的键名**（含 `escape` —— 库只会报 `esc`，
   所以"遥控器返回键"这条映射从一开始就是死的）。
3. **一个自激隐患**：映射表默认把静音键指向 `mute`，而我们自己注入的
   0xAD 在钩子里会被报成 `volume mute`，比对不上 ⇒ 按键一旦真通了就会
   无限自触发。回声防护现在直接问库要别名，实测 27 例全过。
4. 给"死键名"上了闸：`check_keymap.py` 每次 CI 都会拿真实键名清单核对
   `KEY_MAP`，并带 3 条反例自证（改坏就必须报红）。
